# Indian Climate & Air Quality Dashboard (2024–2025)

Interactive Power BI dashboard analyzing AQI, temperature, rainfall
and humidity across Indian cities and states.

Course project: INT374 Data Analytics with Power BI, Lovely Professional University.

## Dataset
Kaggle: Indian Climate Dataset 2024–2025 (7,300+ daily records)
https://www.kaggle.com/datasets/ankushnarwade/indian-climate-dataset-20242025

## Dashboard pages
1. Navigation: buttons linking all pages
2. Overview: KPI cards, state-wise AQI map, AQI trend, city comparison, slicers
3. Climate & AQI Analysis: AQI category donut chart, rainfall and temperature charts, AQI vs temperature scatter plot
4. Detailed Data Table: record-level table with AQI conditional formatting

## Key findings
- AQI varies widely between cities and states
- Clear seasonal pollution patterns
- Higher rainfall periods often show lower AQI

## Tools
Power BI Desktop, Power Query, DAX
